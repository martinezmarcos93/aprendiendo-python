# ADR-020 — HTML, CSS y JavaScript como alfabetización web

- Estado: Aceptada
- Fecha: 2026-09-29

## Contexto
La formación inicial debe incluir Web, pero no tiene como objetivo formar especialistas frontend. La generación de grandes volúmenes de código mediante herramientas de IA reduce el valor de enseñar producción manual extensa como objetivo principal.

## Decisión
El itinerario Web esencial priorizará comprensión estructural, lectura, modificación, depuración y conexión entre HTML, CSS y JavaScript.

HTML cubrirá estructura, elementos y atributos. CSS cubrirá selectores, clases, dimensiones y disposición. JavaScript cubrirá variables, funciones, eventos y manipulación elemental del DOM.

Los desafíos deberán producir resultados visibles y pequeños productos interactivos.

## Consecuencia
Web tendrá menor profundidad que Python, pero seguirá siendo una competencia práctica y verificable.
