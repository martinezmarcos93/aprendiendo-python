# ADR-028 — Fuentes curriculares avanzadas externas

Estado: Aceptada
Fecha: 2026-09-30

Los repositorios curso-python-datos, curso-desarrollo-aplicaciones y curso-orquestacion-streaming-llm se mantienen externos. TortuScript los mapea como fuentes curriculares y adapta cada módulo por edad, dificultad y prerrequisitos antes de publicarlo.
