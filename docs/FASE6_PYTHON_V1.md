# Fase 6 — Python V1 — 29/09/2026

## Objetivo

Convertir el material existente en un itinerario Python coherente y verificable, sin reemplazar de forma destructiva los cursos históricos.

## Decisión curricular

La progresión queda separada en dos capas:
1. Fundamentos previos: Nivel 0 y el curso histórico de TortuScript introducen pensamiento computacional, variables, entrada/salida, condiciones, repetición y funciones.
2. Python V1: python-real convierte esas ideas a sintaxis Python y agrega datos/tipos, listas y resolución de problemas.

El contenido de TortuScript, Tortuga, proyectos guiados y juegos permanece disponible como experiencia pedagógica previa o integradora. No se copia dentro del curso Python.

## Itinerario Python V1

| Unidad | Contenido | Competencias |
|---|---|---|
| Python puente | print, variables, input | entrada/salida, variables |
| Control | if, elif, else, for, while | condiciones, repetición |
| Funciones | def, parámetros y retorno | funciones |
| Primer programa | integración de conceptos | resolución y depuración |
| Datos y tipos | números, textos, booleanos | tipos de datos |
| Listas | índices y colecciones | estructuras de datos |
| Resolver problemas | datos + reglas + procesamiento | resolución, depuración |

## Diseño de actividades

Cada lección mantiene la combinación prevista por el modelo curricular: explicación breve, reconocimiento, predicción, construcción, escritura de código y reto integrador cuando corresponde.

Los nuevos ejercicios de Python declaran explícitamente lenguaje: python, por lo que el motor no debe traducirlos como TortuScript.

## Compatibilidad

No se modifica el formato operativo histórico, el esquema de progreso, CURSO_PRINCIPAL ni el orden histórico de los ejercicios de primeros-pasos.

La ampliación de python-real agrega tres lecciones nuevas y conserva los IDs existentes.

## Fuera de alcance

Fase 6 no implementa Web esencial, SQL, cuentas/cloud, pagos, tutor IA, cursos avanzados externos ni migración total del catálogo al nuevo formato.

## Criterio de cierre

Python V1 debe cubrir variables, datos, condiciones, repetición, funciones, listas y resolución de problemas; registrar las unidades y competencias en el catálogo; pasar tests y validador; y conservar el progreso histórico.
