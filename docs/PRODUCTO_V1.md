# TortuScript — Definición de Producto V1

## Qué es
TortuScript es una plataforma progresiva de aprendizaje tecnológico para niños y adolescentes. El producto actual es el núcleo local de desarrollo de esa plataforma.

## Itinerario inicial
1. Alfabetización tecnológica.
2. Python.
3. HTML + CSS + JavaScript.
4. SQL.
5. Proyecto integrador.
6. Puerta de entrada al nivel avanzado.

## Filosofía
Python recibe la mayor profundidad del itinerario inicial. Web esencial enseña comprensión estructural y capacidad de modificación, porque la producción de grandes cantidades de frontend manual ya no representa por sí sola una competencia moderna. SQL ocupa una profundidad intermedia.

La IA se considera una herramienta que el alumno deberá aprender a utilizar con criterio, no una razón para eliminar los fundamentos. El alumno debe poder leer código generado, detectar errores y describir cambios con precisión.

## Nivel 0
Antes de entrar en un lenguaje se introduce un diccionario interactivo de frontend, backend, navegador, servidor, red, API, datos, bases de datos, seguridad y procesos.

## Gamificación
La gamificación debe reforzar práctica y continuidad, no sustituir el aprendizaje. Se mantienen XP, progreso, logros, rachas y proyectos cuando aporten valor.

## Modelo comercial futuro
La V1 debe representar estados gratuito/premium sin depender de pagos reales. El motor pedagógico recibe una decisión de acceso; la futura plataforma comercial será responsable de identidad, suscripción y autorización.

## Definición de terminado
Producto educativo fundacional verificable y documentado, preparado para evolucionar a plataforma web comercial sin rehacer el motor pedagógico.
