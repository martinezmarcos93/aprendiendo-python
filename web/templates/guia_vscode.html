🧰 Tu proyecto fuera de TortuScript

Cuando termines un proyecto integrador vas a poder abrirlo en tu computadora. VS Code es un editor que te ayuda a trabajar con los archivos.

1. Abrí la carpeta

En VS Code elegí Archivo → Abrir carpeta y seleccioná la carpeta de tu proyecto.

2. Mirá los archivos

El panel de la izquierda muestra los archivos. No todos hacen lo mismo: HTML organiza la página, CSS la presenta y JavaScript agrega comportamiento. Python puede encargarse de la lógica del servidor.

3. Abrí la terminal

La terminal permite escribir comandos. En un proyecto Python podés usar python app.py para iniciar el programa cuando el proyecto lo indique.

4. Leé los errores

Un error no significa que rompiste todo. Mirá el archivo y la línea que indica el mensaje. Volvé al código, hacé un cambio pequeño y probá otra vez.

5. Guardá y comprobá

Guardá el archivo, ejecutá el proyecto y comprobá qué hace realmente. El objetivo es entender el resultado, no solamente conseguir que desaparezca un mensaje rojo.
